## 修复：非首页页面切换空白 bug（22:51）
- **症状**：点击导航切到"关于我/技能/经历/作品/抖音数据/课件设计"任一页面，主区域整片空白，footer 可见
- **根因诊断**（用 Edge headless dump-dom 排除法）：
  - JS 无任何抛错（用 vm sandbox 跑全流程，9 个 render 函数全部成功）
  - DOM 渲染完全正常（page-course 区域 7292 字节，含精准对焦/三步设置法/module-card/highlight-card）
  - 罪魁是 CSS：`@keyframes fadeUp` 被定义两遍（行 240+266），且 `.page.active .section-header` 用 `animation-fill-mode: both` —— backwards 让元素在动画未开始前就停在 opacity:0 状态
- **修复**：
  - 删掉重复 `@keyframes fadeUp`
  - `.page.active` 不再做 opacity 动画（保留位移动画但不依赖 opacity）
  - `.page` 默认 opacity:1（兜底）
  - `.section-header` 的 fadeUp 关键帧 from 改为 opacity:0.6（不再从完全透明起）
  - `.hero-layout`/`.hero-stats`/`.timeline-item` 全部 `both` → `forwards`
  - `triggerRevealAnimations` 加 250ms 兜底：强制给已可见区域的 .reveal 加 .visible，防 IntersectionObserver 不触发时元素永久 opacity:0
- **教训**：CSS 同名 @keyframes 后定义覆盖前面的；fill-mode: both 的 backwards 行为对"动画偶发不触发"敏感，关键内容绝不能让 fill-mode 控制可见性
- 用户提供参考模板：https://www.mobanwang.com/mb/demo/23078/（Alex Chen 极简作品集模板）
- 视觉风格从"深色霓虹"改为"浅色极简"：白底 #ffffff、蓝紫渐变主色 #667eea→#764ba2、柔和阴影卡片
