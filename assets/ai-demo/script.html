📌 演示版说明

  1. 这是什么：输入摄影风格（日系 / 港风 / 夜景等），自动生成完整拍摄方案——服装搭配、动作引导、地点时间、器材光线、构图调色，支持导出图片 / Word / Markdown / PDF。
  2. 演示路径：点风格按钮 → 查看方案 → 点「重新生成」切换方案 B → 点导出按钮保存文件。
  3. 目前能力（3 点）：① 内置 16 个风格完整方案，离线可用，演示最稳；② 每个风格含方案 A / B 两套内容，可一键切换；③ 右上角「设置」填入 AI Key 后，可实时生成任意风格（需联网）。
  4. 关于参考图（当前版）：方案服装均为日常可购买款（白 T、牛仔、碎花裙等），以"摄影师"视角编写；参考图当前以"配色色块 + 文字清单"呈现，保证单文件轻量、离线稳定；日系、港风另有完整样片图（见「拍摄脚本演示」文件夹）。
  5. 参考图上线条件：接入生图 AI（如腾讯混元 / 即梦 / 通义万相等）后，任意风格可实时生成 3 套服装图 + 1 张动作示范图；该能力按次计费（约 0.5-1 元/次），需联网，且 AI 出图需人工筛选后使用。
  6. 演示提醒：本文件为单文件演示版，可直接发给他人离线使用；AI 实时生成需联网和 Key。
