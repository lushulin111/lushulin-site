📌 演示版说明

  1. 这是什么：把老师上课的逐字稿粘贴进来（或点下方按钮一键载入示例），点「生成课堂笔记」，自动产出文字版笔记 + 思维导图版。
  2. 演示路径：点「载入示例1」→ 点「生成课堂笔记」→ 查看两种版本 → 右上切换「发给学员版 / 内部留档版」→ 复制笔记 / 导出思维导图 PNG。
  3. 目前能力（3 点）：① 支持粘贴逐字稿 / 上传 txt / 一键载入示例，离线可用；② 自动提炼：一句话概括 + 核心知识点 + 讲师金句 + 本节作业 + 下节预告；③ 文字版与思维导图同时产出，支持学员版 / 内部留档版切换。
  4. 关于生成逻辑：演示版用「离线规则提炼」模拟 AI——载入内置示例时输出预设标准笔记；粘贴任意自定义逐字稿时按关键词规则提炼兜底。正式版接入大模型（DeepSeek 等）提炼会更准、支持更长的逐字稿。
  5. ⚠️ 上线前必须满足的条件：当前是纯前端离线演示版，要正式给班主任 / 学员用，必须补齐——
    ① 接入后端 + 数据库：逐字稿、笔记、发送记录要存起来，能查历史、能多人共用；
    ② 接入真实 AI 接口：把规则提炼换成调用大模型，支持长逐字稿、更准的提炼；
    ③ 替换真实课程逐字稿：内置摄影示例换成公司真实课程逐字稿；
    ④ 部署为可访问形态：挂公司网址或接入企微 / 售后系统；
    ⑤ 合规口径：笔记不承诺学习效果；如收集学员信息需加隐私告知。
  6. 演示提醒：本文件为单文件演示版，可直接发给他人离线使用，无需联网和 Key。
