📌 演示版说明

  1. 这是什么：按公司品牌框架（固定 LOGO + 配色 + 字体）批量生成大促海报（618 / 双十一 / 通用），支持 AI 写文案、导入参考图、一键换背景、导出 PNG / PDF。
  2. 演示路径：上方「文案生成」填条件→点生成文案；中间「图片设置」选模板 / 尺寸 / 上传 LOGO→点下方「生成图片」出图→点「导出图片」存 PNG。
  3. 目前能力（3 点）：① 内置 3 套大促模板，离线可用，打开即见成品海报（最稳）；② 品牌框架（LOGO / 主色 / 辅色 / 字体）设定后每次出图严格一致，这正是本工具卖点；③ 右上「设置」填 DeepSeek Key 后，可 AI 写文案；填图像 API Key 后，可「重新生成」换 AI 背景（均需联网）。
  4. 关于图片（当前版）：海报背景为内置 AI 生成的样例图，文案为模板示例；LOGO 为占位图，可在「图片设置」上传公司真实 LOGO 与参考图。
  5. 上线条件（4 点）：① 接入图像生成 API（即梦 / 通义万相等）后，可实时生成任意主题背景，按次计费（约 0.5–1 元/次），需联网；② 替换为公司真实品牌资产（LOGO 文件、主色 HEX、指定字体）才能"真"用；③ 需挂公司可访问网址或接企微 / CRM，老师 / 运营才能真正使用；④ 文案与优惠须合规，不承诺效果、不夸大。
  6. 演示提醒：本文件为单文件夹演示版（含 assets 资源），可直接发给他人离线使用；AI 实时能力需联网和 Key。
