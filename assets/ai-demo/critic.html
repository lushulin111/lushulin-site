🛠️ 这是什么？能演示什么？

  • 这是一个「摄影讲师点评」技能的演示版，可完整体验 4 个环节：上传照片 → 摄影讲师点评 → AI 参考图 → 生成推课话术。
  • 点评覆盖 6 大维度（构图 / 光线 / 色彩 / 技术 / 创意 / 后期），支持 5 种点评视角（综合 / 构图 / 光线 / 色彩 / 技术）。
  • ⚠️ 当前页面为模拟演示：点评内容与推课话术由内置示例数据生成，AI 参考图仅展示文字方案，未接入真实 AI。

🚀 正式上线需要什么条件？

  • 点评 / 推课话术功能：接入一个大模型 API（如豆包、DeepSeek、文心一言、通义千问等），把「照片信息 + 点评规则」发给模型，由模型生成点评与话术。
  • AI 生成参考图：另接入一个图片生成 API（如即梦、DALL·E、Stable Diffusion、通义万相等），根据照片生成改进版参考图。
  • 后端服务：需要一个简单后端（或 Serverless 函数）来安全保管 API 密钥、接收图片上传、转发请求，避免密钥泄露到前端。
  • 费用预算：大模型按 token 计费、图片生成按张计费，上线前需评估用量与成本。
  • 域名与合规：正式对外运营建议绑定自己的域名，并注意学员照片的隐私与版权合规。

🗺️ 建议上线流程

  • 第一步：确认接哪家大模型 + 哪家图片生成服务（可先申请免费额度测试）。
  • 第二步：开发后端代理层，把点评规则、提示词固化到服务端。
  • 第三步：前端把「模拟数据」替换为「真实 API 调用」，联调测试。
  • 第四步：小范围内测 → 观察效果 → 正式发布。
💡 提示：演示版适合给领导 / 客户看效果；要真上线，核心工作就是「接入 API + 写后端」，可以随时继续做。
