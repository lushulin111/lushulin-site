# 《精准对焦》课件框架
## 一、课程概览

| 项目 | 内容 |
|------|------|
| 课程定位 | 摄影训练营第一节课（引流课/体验课） |
| 核心目标 | 让学员产生“原来摄影可以这么学”的认知颠覆，提高留人率与作业率 |
| 设计原则 | 底层逻辑先行 + 实战经验落地 + 高频互动 + 软塑造渗透 |
| 核心方法论 | 3W学习法（WHAT → WHERE → HOW） |


## 二、整体递进逻辑

```
┌──────────────────────────────────────────────────────────────┐
│  开场热身 → 建立连接、筛选注意力、制造期待                    │
│      ↓                                                     │
│  课程介绍 → 制造认知冲突、预告3W框架、埋下价值种子            │
│      ↓                                                     │
│  第一部分：对焦的本质（WHAT）                                │
│  → 先“破案”：对焦=瞄准，颠覆“对焦就是变清楚”的认知          │
│      ↓                                                     │
│  第二部分：三步设置法（WHERE）                               │
│  → 起点在镜头（AF/MF）→ 对焦模式（工程师思维 vs 实战版）     │
│  → 对焦区域（瞄准范围）+ 景深认知（杀伤半径）                │
│      ↓                                                     │
│  复盘 + 作业 → 固化认知、行动号召、转化钩子                  │
└──────────────────────────────────────────────────────────────┘
```


## 三、各模块设计要点


### 模块一：开场（约8-10分钟）

**功能定位**：筛选注意力 + 建立信任 + 制造承诺

| 环节 | 设计意图 |
|------|----------|
| 课前预习视频 | 填充空档时间，提前进入学习状态 |
| 声音画面测试 + 666互动 | 筛选注意力，确认设备正常 |
| 课堂纪律（4条） | 用“888敲起来”制造集体承诺感 |
| 自我介绍（8年经验+签约摄影师） | 建立专业信任，降低学员防御心理 |
| 福利预告（50大参数参考大全） | 留人钩子，同时导流私域 |


### 模块二：课程介绍（约3-5分钟）

**功能定位**：制造认知冲突 + 给出课程地图

| 设计要点 | 具体做法 |
|----------|----------|
| 痛点切入 | “网上说AI很智能，为什么你拍出来还是糊？”——制造辩论感 |
| 3W框架预告 | WHAT（本质认知）→ WHERE（系统方法）→ HOW（实战应用） |
| 学习方法论 | 基础阶段用3W学习法，高级阶段用大师学习法（由结果推导过程） |


### 模块三：对焦的本质 WHAT（约20分钟）

**功能定位**：建立核心认知，让学员“心里有底”

| 知识点 | 教学策略 |
|--------|----------|
| 对焦=拍摄前的瞄准 | 用“打靶”比喻贯穿全程，先提问再给定义 |
| 标准三步动作 | 视频演示 + 强调两个“大坑”（跑焦 / 一把按到底） |
| 两条基础规则 | 拍人对眼睛 / 拍景找主体——用口诀记忆 |
| 两种对不上焦的情况 | 纯色区域（找边界）+ 靠太近（后退一步法）——用“我写你们记”强化 |


### 模块四：三步设置法 WHERE（约45-50分钟）

**功能定位**：给出系统方法，让学员从“被动服从”变“主动指挥”

**整体设计逻辑**：每步都用“底层逻辑 → 常见误区 → 实战结论”三段式推进。


#### 第一步：AF / MF（起点在镜头上）

| 设计要点 | 具体做法 |
|----------|----------|
| 认知反转 | “很多人第一步就走反了——正确起点在镜头上，不在机身菜单里” |
| AF/MF含义 | AF解决95%场景，MF只用于3种特定场景 |
| 破除执念 | “用MF不代表更专业，胶片时代的产物而已” |
| 三种MF场景 | 创意光斑 / 隔玻璃拍摄 / 固定机位批量拍摄 |


#### 第二步：对焦模式（AF-S / AF-C / AF-A）

**核心教学策略**：先讲“工程师怎么想”，再讲“实战中怎么用”

| 设计要点 | 具体做法 |
|----------|----------|
| 工程师思维 | 按“动静”分类：静止→AF-S / 运动→AF-C / 静中带动→AF-A |
| 说明书 vs 实战 | 说明书版是“一对一匹配”，实战版揭示AF-A的BUG |
| BUG揭示（爆点） | AF-C的“近水楼台先得月”逻辑→识别最近/反差最大→风吹草动就跑焦 |
| 实战结论 | 95%用AF-S，5%用AF-C，AF-A坚决不用 |


#### 第三步：对焦区域（单点 / 区域 / 广域）+ 景深认知

**对焦区域部分**：

| 设计要点 | 具体做法 |
|----------|----------|
| 是什么 | 对焦区域 = 瞄准范围 |
| 核心结论 | “对焦区域越小，对焦越精准”（先设配合点“开最大是不是更好”再反转） |
| 怎么用 | 静止→单点 / 小范围动→区域 / 大范围乱跑→广域 |
| 区域误区 | 用“近水楼台先得月”强化学员认知，让学员自己推导出“相机会对栅栏” |
| 配合点设计 | “老师，区域不是更省事吗？”→揭示“自作聪明”的后果 |

**景深认知部分**（大合影场景切入）：

| 设计要点 | 具体做法 |
|----------|----------|
| 选择题互动 | 大合影选什么对焦区域？→90%选广域→反转答案：单点 |
| 打靶比喻打通 | 对焦=瞄准镜（打哪个点）/ 景深=杀伤半径（炸多大范围） |
| 光圈控制景深 | 小光圈（F13以上）→景深变大→前后都清晰 |
| 两步操作 | ①调小光圈②点对焦瞄准 |
| 中庸思维 | 新手选中间不出错 / 有经验的摄影师选中间靠前（因为后景深>前景深） |


### 模块五：复盘 + 作业（约10分钟）

**功能定位**：固化认知 + 行动号召 + 转化钩子

| 环节 | 设计意图 |
|------|----------|
| 前后对比 | “开课前一头雾水 vs 现在能自己诊断问题”——制造成就感 |
| 对焦急救手册（五句话） | 可带走的记忆卡片，增加获得感 |
| 二选一作业 | 降低完成门槛，提高作业率（作业完成者付费转化率更高） |
| “行动”互动 | 公开承诺，提高执行力 |
| 下节课预告 | “用光来写诗”——制造期待，为下一节课留人 |


## 四、设计亮点总结

| 亮点 | 说明 |
|------|------|
| 打靶比喻贯穿全课 | 对焦=瞄准 / 对焦区域=瞄准范围 / 景深=杀伤半径，用一个比喻打通三个概念 |
| “我写你们记” | 在4个关键知识点让学员动手写，动作绑定记忆 |
| 说明书版 vs 实战版 | 先讲官方逻辑让学员理解，再给实战版本揭示坑在哪 |
| 软塑造不硬推 | 用“网上短视频不会告诉你”“自学几年搞不懂”渗透价值，而非直接推销 |
| 配合点设计 | 模拟学员真实疑问，制造“有人替我提问”的参与感 |
| 3W框架贯穿 | WHAT → WHERE → HOW，从认知到方法到应用 |


## 五、市场转化逻辑

| 转化目标 | 课程中的设计 |
|----------|-------------|
| 留人率 | 痛点共鸣开场 + 高频互动 + 认知反转制造“啊哈时刻” |
| 作业率 | 二选一 + 低门槛 + 公开承诺“行动” |
| 付费转化 | 软塑造贯穿 + 下节课预告“用光写诗” + 作业完成者转化率更高 |

---

> **备注**：本框架适用于摄影训练营第一节课。课程配套材料包括：PPT课件、逐字稿、对焦急救手册（学员可带走）、50大相机参数设置参考大全（福利钩子）。
